Required Dependencies:

- Axis 1.4.1
- Java Saml Core 2.9.2
- Yellowfin Webservice library (that matches your installation of Yellowfin)
- Reload4j 1.2

There are multiple vulnerabilities in Axis 1.4 and Log4j 1.2.
An unreleased version of Axis 1.4.1 exists at https://github.com/apache/axis-axis1-java with patches for vulnerabilities
Reload4j (from https://reload4j.qos.ch/) can be used as a replacement for Log4j 1.2, which has patches for vulnerablities

download_dependencies.sh has been provided to download these libraries.

This will download all dependencies except for: 

 - yfws.jar file (Yellowfin Webservice Library that needs to match the version of Yellowfin in use).
 - axis-rt-core-1.4.1-20230921.jar (which can be sourced from a Yellowfin installation or manually built from the code at https://github.com/apache/axis-axis1-java)
